# Shubhada Portfolio — GitHub Pages

Static HTML/CSS/JavaScript version of the portfolio mockup.

## Files
- index.html — page structure/content
- style.css — responsive design
- script.js — mobile navigation, scroll reveal and smooth scrolling

## Before publishing
1. Replace the photo placeholder in `index.html` with your actual photo.
2. Add your resume at `assets/Shubhada-Resume.pdf`.
3. Replace `your@email.com`, LinkedIn, GitHub and WhatsApp `#` links.
4. Replace project placeholders with your real project screenshots/links.
5. Push all files to the root of your GitHub Pages repository.

## GitHub Pages
Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
