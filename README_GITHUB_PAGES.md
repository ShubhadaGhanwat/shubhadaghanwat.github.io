# Shubhada Ghanwat Portfolio

A responsive React + Vite portfolio customized for Shubhada Ghanwat using the information from her resume.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## GitHub Pages

The included GitHub Actions workflow automatically sets the Vite base path from the repository name.

In GitHub, open **Settings → Pages** and set **Source** to **GitHub Actions**.

Push the project to the `main` branch and the workflow will build and deploy the site.

The CV is included as `public/cv.pdf` and the profile image as `public/shubhada.png`.
