# Picto Portfolio — GitHub Pages

This is a React + Vite portfolio template prepared for GitHub Pages.

## Fast deployment

1. Create a **public** GitHub repository.
2. Upload all files from this folder to the repository root.
3. Commit to the `main` branch.
4. In GitHub open **Settings → Pages**.
5. Under **Build and deployment**, choose **GitHub Actions**.
6. Open the **Actions** tab and wait for the `Deploy to GitHub Pages` workflow to finish.
7. Your site will be available at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

If your repository itself is named `YOUR-USERNAME.github.io`, the site will use the root URL `https://YOUR-USERNAME.github.io/`.

## Run locally

Requires Node.js 20+.

```bash
npm install
npm run dev
```

## Customize

Replace `Your Name`, email, project text, social links, and project URLs in `src/components/`.

The current template uses placeholder project images and a placeholder CV link. Add `public/cv.pdf` if you want the Download CV button to work.
